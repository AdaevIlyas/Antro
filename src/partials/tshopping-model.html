Модель проекта

Создаем универсальный модуль
для 1С-Битрикс

После его разработки подключение
Т-Шопинга сводится к настройке модуля и адаптации под особенности конкретного интернет-магазина, а не к разработке интеграции с нуля

Цена участия

Мы уже рассчитали стоимость создания универсального модуля для 1С-Битрикс. Она будет разделена между всеми участниками пула.

Наша цель — сделать подключение настолько доступным, чтобы брендам было выгоднее присоединиться к общей разработке, чем создавать аналогичную интеграцию самостоятельно.

Если нам не удастся собрать достаточный пул компаний, проект просто не будет запущен.
